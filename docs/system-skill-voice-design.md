# 无法官白天技能播报：设计草案（尚未接入）

> 文档定位：已确认的目标设计和接入验收项；独立原型及旧计时不代表目标流程已经实现。关联进度见 [当前状态](./current-status.md)。

本文件记录已确认的需求；当前游戏仍使用原有五秒计时，下面不是已上线功能。

## 已确认

- 公共语音由无法官模式的控制设备播放，不能由每位玩家的手机同时播放。
- 所有出局玩家都经过“等待玩家发动技能”的公共窗口，不因角色、被毒或技能失效而省略；有能力的玩家可以在提示或倒计时期间提前操作，操作成功后立即进入下一步。提前结束可能暴露有人进行了操作，此取舍已由用户确认。
- 暗黑破坏 2.0 在复活未使用前对每位出局者都等待天使长，即使天使长出局、被禁锢或目标不可复活，也维持相同提示和等待；实际按钮仅提供给符合条件的天使长。复活使用后不再询问。
- 定序王子只在白天首轮放逐结果生效前询问，不适用于夜间或其他方式出局；即使王子已出局也保留该询问，回溯使用后不再询问。
- 带人造成新的出局时，对每名新出局者按天使长复活窗口、该玩家死亡技能窗口的顺序递归结算；复活成功则该玩家不发动死亡技能，所有连锁处理完成后再推进。
- 定序王子、天使长等以各自角色名称提示；猎人、狼王、机械猎人等死亡技能统一播报“等待玩家发动技能”。
- 播报完整结束后才开始 5、4、3、2、1 倒计时。语音未能播放、控制设备锁屏或中断时不得超时，需提示控制设备恢复/重播。允许提前操作，成功后终止当前提示与倒数。

## 接入时必须验证

1. 服务器状态驱动流程：控制设备报告当前窗口的播报及倒数已完成；超时只在播报确认、完整五秒及倒数完成之后生效。客户端的显示、系统时钟或单独的定时器不能决定游戏结算。
2. 每个窗口及重播尝试具有独立标识；过期语音回调、重复请求、控制权转移、网络重试不得结束其他玩家的窗口。
3. 启用技能后要取消旧语音，连续窗口不能相互覆盖；失去控制设备、声音被禁用或自动播放被浏览器拒绝时必须停住，提供明确的人工恢复入口。
4. 普通玩家出局、夜间多死、白天放逐、自爆、猎人/狼王带人、延迟死亡、天使长复活和胜负判定均覆盖；法官模式不使用自动播报等待。
5. 虚拟等待不暴露技能拥有者、是否可开枪或天使长是否可复活；普通玩家不能提交技能，控制设备和未授权玩家不能查看隐藏身份。
6. 分别验证本地服务和 Pages/D1 的并发、安全与重试；再做真实手机语音、静音、锁屏和断网测试。单元测试通过不等同于上线。

独立的 `web/skill-voice-window.js` 目前只提供计时状态机原型，**未与服务器、播放器或出局流程连接**。
