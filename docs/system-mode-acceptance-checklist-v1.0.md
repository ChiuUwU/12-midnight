# 无法官模式真实设备验收清单

上线候选版本必须由控制设备和至少两台不同玩家设备共同完成。自动测试不能替代本清单。

## 准备

- 控制设备：桌面 Chrome 或 Edge，创建无法官房间。
- 玩家设备：至少一台 Android Chrome 与一台 iPhone Safari；可用无痕窗口补足不同玩家会话。
- 记录浏览器版本、网络环境、房间号和失败步骤；不得记录任何未公开身份或夜间目标。

## 必测项

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 未提交选择保留 | 玩家选中夜间目标、女巫选项或盗宝牌后等待一次轮询 | 选择不消失，提交后才进入下一步 |
| 十秒播报 | 任一玩家提交行动 | 控制设备等待十秒后播报下一步；首个夜间步骤不额外等待 |
| 断网恢复 | 当前行动设备断网、恢复网络并刷新 | 身份和可行动状态正确恢复，不重复提交或重复播报 |
| 并发提交 | 狼队两台设备同时提交不同刀口 | 服务端最先成功的合法请求生效，另一台显示步骤已更新且不能覆盖 |
| 发牌前转让 | 控制设备生成六码，新设备接管，旧设备选空座 | 新设备获得控制权，旧设备可入座 |
| 发牌后转让 | 已发牌后重复上述接管 | 新设备接管，旧设备不能进入已锁定座位 |
| 超时处理 | 创建房间选 60 秒超时，等待到期 | 仅控制设备看到超时操作；继续等待、重播、强制跳过均符合预期 |
| 强制跳过 | 对狼人和神职步骤分别强制跳过 | 狼人空刀；神职不发动技能；日志可复盘 |
| 隐私 | 非当前行动玩家刷新页面 | 看不到当前角色、行动目标、女巫刀口或控制权转让码 |

## 版型回归

- 预女猎白混：女巫首夜不能自救、白神放逐提示。
- 盗宝大师：三张盗宝牌、蒙面人最终一夜、转让后控制设备不泄露身份。
- 唯邻是从：首夜傀儡选择和傀儡技能失效。
- 其余四个版型：至少完成一夜、一日和进入下一夜。

验收完成后，在 `current-status.md` 记录日期、设备组合、通过项及未通过项；未通过项不得仅凭自动测试关闭。
