# 2026-11-01 当前版本发布快照

## 决策与状态

用户选择先保存到 GitHub 并发布 Cloudflare，再修复无法官审查发现的缺陷。本快照不包含这些缺陷的修复，不代表无法官模式通过完整验收。本文是发布候选说明；GitHub 推送、PR 合并与 Cloudflare 部署是否完成，必须以各服务实际记录为准。

范围：当前正式项目代码、九个版型与规则文档、规则构建、管理员接口、月夜 UI、新卡面及保留的旧卡面。第二张生成标题图片仍为素材候选，正式首页不因此自动切换。备份、个人工具配置和本地静态预览不上传。

## 已知缺陷（后续修复，不在本次顺带处理）

1. Pages 心跳保存会增加业务 revision，可能让同一步骤的合法提交返回 409；前端冲突后重绘可能清空选择。
2. 公共控制端收到完整白天技能窗口，其中 `eligibleSeats` 泄露定序王子号码。
3. 固定夜间计时目前只接入预女猎白混、诡术之境、机械狼通灵师；另外六个版型仍走旧计时。
4. 部分未接入版型会跳过死亡角色步骤；暗黑破坏尚未始终保留未充能时的迷雾询问，会泄露状态。
5. 定序王子回溯后，直接录入最终放逐结果入口被拦截，需改用手机重投或完整线下票型录入。

回归基线为本地 109 项测试通过，不等于上述缺陷消失。新增只读对抗检查另已复现这些问题。未完成真实手机声音、锁屏、断网恢复、多设备整局与生产 D1 验收。

## 发布要求

- 通过独立分支 PR 合并到 `main`，保持现有 Pages/GitHub 连接，不新建站点、不覆盖已有绑定。
- 保留旧版 `v1` 标签；发布前记录远程 main 和 Pages 当前成功生产部署。若不能联网核实，应停止声称已完成发布。
- `node scripts/build-rulebook.js --check` 必须通过；已提交 `web/rulebook-data.json`，即使原 Pages 构建命令为空，也有对应生成内容。现有构建配置如需修改应先读取再合并，不能覆盖未知配置。
- D1 仍使用现有 `DB` 绑定。新档案和管理员表是追加建表；不删除或重置旧表。管理员 `ADMIN_PASSWORD` 由所有者在 Cloudflare 设置为加密 Secret，密码不入 Git、不发对话；未配置时管理员功能保持不可用。
- 部署成功后再核对首页资源、规则与 `/api/rooms`；GitHub 推送或 PR 合并不等于 Cloudflare 发布成功。

回滚优先使用 PR 的 Revert 或 Cloudflare 已验证的前一成功部署；不要强推或覆盖对局数据库。新增功能产生的档案表和已记录数据应保留。
