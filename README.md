# 最后一夜 Last-Night

**天黑了，请闭眼。**

有些故事从一张身份牌开始，有些真相藏在每一次睁眼与闭眼之间。「最后一夜」是为线下狼人杀聚会制作的手机优先网页工具：让法官更轻松地记录流程，也让没有法官的玩家尝试由系统主持游戏。回到桌前，重新开局。

## 游戏使用

1. 打开已部署的网站，或按下方方法启动本地服务；创建房间并选择版型和模式。
2. 玩家加入房间，分别选择座位；准备完成后发牌并私密查看身份。
3. 有法官模式由法官使用面板记录和主持；无法官模式由玩家和控制设备配合操作。网页中可查看版型规则。
4. 按实际提示处理夜间行动、白天流程和出局结算。复杂规则、无法官计时与真实多设备体验仍有待开发或验收，具体见当前状态，不应仅凭自动测试结果判断可以正式主持。

双击 HTML 为单浏览器静态演示，不能模拟跨设备同步；若要测试联网房间，请启动本地服务或使用已部署的测试环境。静态文件下规则页面的可用性也不能替代 HTTP/线上验证。

## 开发与验证

需要 Node.js 18 或更高版本。在项目目录执行 `npm start`，访问 `http://localhost:5173`；本地服务的房间保存在内存中，重启后会消失。Windows 也可双击 `start-web-server.cmd`。同一网络的手机可使用启动窗口显示的局域网地址访问，具体还受防火墙设置影响。

- `npm test`：运行自动化测试；不能替代真实手机、语音、Cloudflare Pages 和 D1 验收。
- `npm run build:rulebook`：根据 Markdown 源文件生成网页规则数据。
- `npm run watch:rulebook`：监听规则源文件变化，本地自动重新生成。
- `node scripts/build-rulebook.js --check`：检查规则数据与源文件是否一致。

`web/` 是网页和共享逻辑，`server.js` 是本地 Node 服务，`functions/` 是 Pages 接口，`db/` 存放数据库结构，`tests/` 是自动化测试。三种运行路径并非完全共用实现，改动时需要分别核对。

当前工作区配置了九个版型：预女猎白混、假面舞会、盗宝大师、机械狼通灵师、诡术之境、曙光航纪、狼王守卫、唯邻是从、暗黑破坏 2.0；**工作区存在配置不等于已上线或已验收**。

# 历史说明：十二点天黑

狼人杀发牌/流程辅助工具。

当前优先实现为手机网页版，避免微信小程序注册、类目、审核和开发工具配置带来的额外成本。小程序版本代码暂时保留，后续如果需要可以再迁移。

第一版网页版目标是跑通线下开局的最小闭环：

- 创建房间
- 加入房间
- 绑定 1-12 号座位
- 选择固定版型
- 均衡随机发牌（2000 套合法候选加权抽取）
- 玩家私密查看身份
- 法官查看全局身份
- 复盘身份与关键操作

## 预览

网页版入口：

- [web/index.html](./web/index.html)

当前网页有两种运行方式：

- 直接打开 `web/index.html`：本地演示模式，数据只保存在当前浏览器。
- 双击 `start-web-server.cmd` 后打开 `http://localhost:5173`：本地联机模式，支持同一台电脑服务下多设备加入同一个房间。
- 部署到 Cloudflare Pages + D1：线上免费联机模式，手机不需要和电脑在同一个 Wi-Fi，部署步骤见 [Cloudflare 免费部署](./docs/cloudflare-deploy.md)。

本地测试流程：

1. 双击 `start-web-server.cmd`。
2. 在电脑浏览器打开 `http://localhost:5173`。
3. 创建房间。
4. 选择版型。
5. 选择自己的座位。
6. 用其他浏览器或手机打开分享链接加入房间，或点击“补齐测试座位”。
7. 发牌。
8. 查看身份、法官总览和复盘。

手机访问时，启动窗口会显示类似 `http://192.168.x.x:5173` 的地址。手机和电脑需要在同一个 Wi-Fi 下。如果手机打不开，通常是 Windows 防火墙没有放行 Node.js。

## 注册类目建议

建议注册为普通小程序，选择非游戏类目中最贴近的工具/其他类目，不建议选择“游戏”类目。

原因：

- 本项目是线下狼人杀的发牌和流程辅助工具，不是在微信内直接游玩的小游戏。
- 当前代码使用普通小程序结构：`app.json`、多页面、WXML、WXSS。
- 微信小游戏会走小游戏开发形态和审核要求，涉及游戏资质、小游戏特别规范和不同的代码组织方式。
