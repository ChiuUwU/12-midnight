# 无法官模式真实设备验收清单

> 文档定位：真实设备验收参考，自动化通过不等于已完成此清单；应结合 [当前状态](./current-status.md) 和 [统一改造计划](./unified-flow-implementation.md) 中仍未接入的目标使用。

上线候选版本必须由控制设备和至少两台不同玩家设备共同完成。自动测试不能替代本清单。

## 准备

- 控制设备：桌面 Chrome 或 Edge，创建无法官房间。
- 玩家设备：至少一台 Android Chrome 与一台 iPhone Safari；可用无痕窗口补足不同玩家会话。
- 记录浏览器版本、网络环境、房间号和失败步骤；不得记录任何未公开身份或夜间目标。

## 必测项

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 未提交选择保留 | 玩家选中夜间目标、女巫选项或盗宝牌后等待一次轮询 | 选择不消失，提交后才进入下一步 |
| 十秒播报 | 任一玩家提交行动 | 控制设备等待十秒后播报下一步；首个夜间步骤不额外等待 |
| 断网恢复 | 当前行动设备断网、恢复网络并刷新 | 身份和可行动状态正确恢复，不重复提交或重复播报 |
| 并发提交 | 狼队两台设备同时提交不同刀口 | 服务端最先成功的合法请求生效，另一台显示步骤已更新且不能覆盖 |
| 并发入座 | 多名玩家短时间内选择不同号码；另两人争选同一号码 | 不同号码的选择均保留；争抢同一号码时只一人成功，另一人看到最新占用状态并可改选其他空位；不因版本刷新提示卡住 |
| 发牌前转让 | 控制设备生成六码，新设备接管，旧设备选空座 | 新设备获得控制权，旧设备可入座 |
| 发牌后转让 | 已发牌后重复上述接管 | 新设备接管，旧设备不能进入已锁定座位 |
| 超时处理 | 创建房间选 60 秒超时，等待到期 | 仅控制设备看到超时操作；继续等待、重播、强制跳过均符合预期 |
| 强制跳过 | 对狼人和神职步骤分别强制跳过 | 狼人空刀；神职不发动技能；日志可复盘 |
| 隐私 | 非当前行动玩家刷新页面 | 看不到当前角色、行动目标、女巫刀口或控制权转让码 |
| 白天阶段与下一夜 | 有法官模式分别尝试漏记天亮死讯、漏记放逐/无人出局、漏记警长流程；无法官模式漏记最终白天结果 | 按钮始终可见、可点击；必要记录缺失时服务端给出具体提示；警上、退水和警徽记录不阻塞 |
| 白天可选技能窗口 | 分别触发定序王子回溯、天使长复活、猎人/狼王死亡技能 | 各窗口依次倒计时 5 秒；超时按不发动结算；处理前一个后才开始下一个计时 |
| 延迟死亡与未完成投票 | 让蒙面延迟死亡待确认，或只提交部分暗黑私密投票后尝试进入下一夜 | 两者不会被 5 秒技能窗口跳过；按钮请求被拒绝并指出待处理流程 |
| 警长延期竞选 | 首次警长竞选期间狼人自爆，再于次日延期竞选期间再次自爆 | 首次自爆后进入下一夜并延期竞选；第二次自爆后警徽流失 |
| 撤回夜间行动 | 完成含动态步骤的行动后连续撤回一项 | 最近行动及其动态状态恢复；回到被撤回的步骤，不重复之前已完成步骤 |

## 版型回归

- 预女猎白混：女巫任意夜晚不能自救、白神放逐提示。
- 狼王守卫：狼王可参与共享刀口；同守同救按奶死结算，猎人/狼王按非毒杀死亡判定技能。
- 盗宝大师：三张盗宝牌、蒙面人最终一夜、转让后控制设备不泄露身份。
- 唯邻是从：首夜傀儡选择和傀儡技能失效。
- 其余四个版型：至少完成一夜、一日和进入下一夜。
- 暗黑破坏 2.0：核验莉莉丝、首夜莉娅举手、其余夜间角色、莉娅充能/开雾按单一流程推进；结算后不重复显示莉莉丝或莉娅步骤。完整投票需覆盖莉娅私看逐座位票型、法官可查看、其他玩家只见公开结果。

验收完成后，在 `current-status.md` 记录日期、设备组合、通过项及未通过项；未通过项不得仅凭自动测试关闭。
