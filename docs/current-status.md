# 当前状态与发布基线

更新时间：2026-10-24。本文记录当前实现与待验收状态；线上部署状态以 Cloudflare Pages 构建记录为准。

- 最新已获取的 `main` 提交：`67208e8`（合并狼王守卫版型与全版型女巫规则）。
- `v1` 回档标签指向旧版提交 `12ef1c2`；本次功能分支包含 `d37a4f0` 与最新 `main` 的合并，尚未部署到线上。
- 2026-10-24 合并候选版本 `npm test`：45/45 通过；不代表线上 Pages 或真实手机端已验收。

## 已实现范围

- 八个固定版型：预女猎白混、假面舞会、盗宝大师、机械狼通灵师、诡术之境、曙光航纪、狼王守卫、唯邻是从。
- 有法官与无法官两种房间模式；无法官模式支持玩家各自手机提交私密夜间行动、公共设备播报和公开结果。
- 夜间结算由共享规则模块计算；法官模式须记录当日天亮死亡与放逐结果后才能进入下一夜。上警、退水、警徽记录为可选。
- 夜间和房间轮询不会重绘带有未提交选择或输入的页面，避免清空用户操作。
- 女巫整局不可自救，同一晚只能使用一种药；同守同救按“奶死”的非毒杀死亡处理。
- 有法官模式可在未发生后续派生结算时撤销最近一条当日死亡或放逐记录并重新填写；撤销保留审计日志。
- 通用夜间目标映射已建立首个共享实现：魔术师换号保留原始目标、映射链与实际目标的审计快照；旧房间记录兼容原有结算。尚未据此新增魔幻对决版型。
- 白天即时技能窗口与私密信息/死亡记录已有首版通用结构，并接入定序王子回溯等现有流程；尚未覆盖所有未来技能类型。
- 狼王守卫已接入网页、本地服务、Pages Functions 与均衡发牌，并已合并到 `main`；本次分支还未发布。

## 仍需验收或后续处理

- 真实浏览器与手机端验收由产品负责人进行，重点覆盖夜间选择保留、女巫任意夜晚不可自救、无法官十秒播报、八个版型的完整流程；狼王守卫应重点验收狼王共享刀口和同守同救奶死。
- 无法官模式已有可配置行动超时、六位控制权转让码（五次错误锁定）和基于房间版本的陈旧提交拒绝；真实多设备争抢与断线恢复仍需浏览器/手机验收。
- Pages Function 的房间更新与发牌历史/结果统计采用 CAS 绑定副作用；真实 D1 并发与 Pages 构建仍需部署后验收。

## 已确认的后续开发标准

- 暂不为了常见名称或少量身份替换而扩充固定版型；有法官局可以线下稳定裁定的替代玩法，不构成原生开发的充分理由。
- 新版型优先复用能力而非增加专用分支。通用夜间目标映射、白天即时技能窗口、私密信息与死亡记录机制已进入首版实现；临时技能来源的通用建模及更多角色接入仍待后续。详细边界见 [`rule-data-structure-v0.1.md`](./rule-data-structure-v0.1.md) 的“8.5 先能力、后版型的开发标准”。
- 真实多设备验收完成前，不启动会重构白天流程或扩大夜间结算面的高风险版型实现。
- D1 当前保存整间房间 JSON；房间量显著增长后再评估拆表。
