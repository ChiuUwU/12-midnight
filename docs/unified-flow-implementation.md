# 夜间与出局结算统一改造计划

> 进度提示（2026-10-31）：部分有法官步骤与狼人新卡面已在工作区更新；下方总体任务和验收边界仍需逐项核对，不能视为全部完成或已发布。详见 [当前状态](./current-status.md)。

状态：开发中；不要将本计划或独立原型视为已完成或可发布。

1. 建立各版型共享的普通狼刀资格；特殊狼接刀条件仅私密告知本人，普通狼刀与机械技能刀分开。盗宝狼人牌不另产生一刀。进度：共享资格已接入三个运行路径，独立的私密确认步骤尚未实现。
2. 固定夜间步骤展示：身份出局、被禁锢或用完技能均不改变公共流程；首夜专属步骤除外。法官看到不可操作状态；无法官只对合资格者开放操作。当前三个运行路径仍按生存/技能过滤步骤，未完成。
3. 普通步骤 60 秒、狼刀基础 120 秒，最多两次各 20 秒加时，确认后在基础及加时结束后进入不因改刀重置的 10 秒窗口；未行动则空过，首夜必选步骤超时等待。步骤间 5 秒；统一以服务器时间和版本控制结算。当前 `night-timing-policy.js` 只是独立原型，未连接房间流程或音频。
4. 出局统一队列：每位出局者先执行符合版型的天使长询问，再询问该玩家死亡技能；连锁带人递归排队，复活者不执行死亡技能，全部结算后判断胜负。天使长使用过复活后不再询问；回溯仅在每日首轮放逐结果生效前询问，用过后不再询问。假窗口不向他人暴露角色或技能资格。当前已有部分真实技能窗口，尚无所有出局者的统一询问队列。
5. 无法官语音：控制设备授权播放，失败/中断时停住；播报完毕后才开始倒计时并播报，旧回调、重复提交、控制权转移不得跳过其他窗口。当前 `skill-voice-window.js` 只是一份未接入原型，不能证明实际播放或状态推进正确。
6. 三种运行路径分别测试：静态 HTML、本地 Node 服务、Cloudflare Pages/D1；涵盖权限、并发、撤回、断线、跨夜、游戏结束、特殊技能和隐私，并检查旧房间兼容。真实手机语音、后台、锁屏、实际 Pages/D1 尚需单独验收。
7. 管理员界面需要线上配置和安全验收；狼人卡面生成候选并保留旧图，最终视觉需用户确认；首页设计与真实手机体验待用户确认。上线前不得将局部自动测试成功等同全部完成。
