# 最后一夜 · 全站视觉规范

本轮仅覆盖网页 UI，不包含小程序。首页已确认的月夜场景与题字保持不变；业务流程、版型、角色代码和数据不在视觉改造范围内。

## 视觉层

- 加载顺序：原 `styles.css` → 已确认 `home.css` → 全站覆盖层 `ui-theme.css`。
- `ui-theme.css` 作用于非首页视图，以现有类名换肤；不新增流程、不修改 DOM、不重排操作、不隐藏控件，不新增点击遮罩。
- 原共享 CSS 与首页 CSS 原样保留，回滚只需撤销最后一层引用。
- 使用现有 Sites 的本地预览与验证流程；没有安装第三方技能、组件库或运行依赖。

## 设计标尺

| 用途 | 规范 |
| --- | --- |
| 基底 | 月夜深蓝 `#09141d`；操作区域使用高不透明深蓝表面，背景只作为衬底 |
| 重点 | 古金 `#dbc18a`；危险操作用低饱和浅红，选中状态用金色填充配深色字 |
| 正文 | 16px 系统中文无衬线，行高 1.75～1.9 |
| 辅助 | 14px，不再使用 11～13px 的密集说明 |
| 控件 | 18px；密集选项 16px；高度不低于 44px |
| 章节／页面标题 | 20～24px／32px，统一宋体展示字；首页四字题字使用已有本地字体 |
| 间距 | 8px 基准；条目 16px；主要面板 24px；320px 窄屏面板 16px |
| 圆角 | 面板 6px，按钮、选择项、标签 3px；不堆叠大圆角胶囊 |

首页与主要操作沿用金色文字的低边框处理；座位、药剂等选择型控件保留必要边界及明显选中态。危险、禁用、选中不能只靠轻微文字颜色区分。装饰字体不用于长段规则和法官台词。

## 验证

- `node scripts/ui-theme-gallery.js`：使用未修改的 app.js 渲染 47 个只读合成样本，九个版型的白天／夜间／规则与通用记录、身份、投票、技能窗口等；核对本轮基线 26 个文件 SHA256。
- `node scripts/ui-theme-browser-check.js`：检查 320／390／430px 视口、字号、控件尺寸与主题启停前的控件显隐／禁用状态一致；截图目录 `analysis-output/full-ui-theme-20261101/`。
- 合成样本不是真实对局。通过现有 `browser-smoke.js` 和 `homepage-browser-check.js` 另行验证真实本地入口、房间与无法官首夜；语音完成回调为模拟，不代表真实手机声音／锁屏已验收。
- 控制器后台与真实多手机对局验收不是 CSS 换肤可替代的事项。
