# 无法官模式 v0.1

> 发布状态（2026-08-29）：功能已合并至线上 `main`（`e5ce7f8`），自动化测试 36/36 通过；真实多设备验收因设备不足暂缓，恢复时按 [`system-mode-acceptance-checklist-v1.0.md`](./system-mode-acceptance-checklist-v1.0.md) 执行。

## 定位

无法官模式仍然服务线下狼人杀，不把发言、上警、投票和唱票搬到线上。

- 玩家手机：私密看牌、仅在轮到自己身份时提交夜间行动。
- 公共控制设备：发牌、开始夜晚、语音播报、公布公开死讯、记录白天最终出局结果。
- 服务端：校验行动权限、推进步骤、统一结算、保存刷新恢复所需状态。

## 权限边界

- 无法官房主拥有 `isController`，但 `isJudge` 永远为 `false`。
- 控制设备不能占 1-12 号座位，也不能获取身份总览、夜间行动或死亡原因。
- 普通玩家只获取自己的身份。
- 等待玩家只能看到通用等待状态，不获取当前行动角色和台词。
- 当前身份玩家只获取当前一步和必要的私密上下文。
- 狼队步骤允许当前版型中会进入狼队的存活角色共同操作，服务端只接受第一个有效统一刀口。

## 已实现流程

1. 控制设备创建 `SYSTEM` 房间并分享链接。
2. 12 名玩家各自在手机选择座位。
3. 控制设备发牌，但看不到任何身份。
4. 玩家私密查看自己的身份。
5. 控制设备开始夜晚并按步骤自动语音播报。
6. 对应身份玩家在自己手机提交行动；其他玩家提交会被服务端拒绝。
7. 控制设备轮询步骤，身份提交后自动播报下一步。
8. 预言家、通灵师、机械查验、机械模仿、假面验舞池结果只随提交响应返回本人。
9. 女巫本人在有解药时只获取当夜刀口。
10. 所有步骤完成后，控制设备结算并公布天亮死讯。
11. 蒙面延迟死亡和死亡技能只向对应玩家本人显示待办。
12. 公开死亡、开枪和白天放逐通过公共事件由控制设备自动播报。
13. 控制设备只记录线下白天产生的最终出局结果或无人出局；未记录不能进入下一夜。
14. 游戏结束后公开完整身份和复盘记录。
15. 存活狼人阵营玩家可在白天由本人手机确认自爆；系统只公布自爆座位、不公布具体身份牌，并结束白天。若有死亡技能先处理，否则立即进入下一夜。
16. 当前控制设备可生成一次性六位转让码；新设备接管后旧控制 token 立即失效。发牌前，旧设备可选择空座位成为玩家；发牌后，旧设备只能作为旁观设备，不能加入已锁定的 12 人对局。
17. 创建无法官房间时可选择关闭、60、90 或 120 秒的夜间行动超时。超时后仅控制设备可继续等待、重播提示或强制跳过；强制跳过时狼人空刀、神职不发动技能。

## 刷新策略

- 远程房间每 2.5 秒同步房间状态。
- 页面存在未提交的座位、卡牌、女巫选项、输入框或下拉框改动时，只同步内部状态，不重绘页面，避免清空用户操作。
- 用户提交、切换页面或主动刷新房间后再按最新状态渲染。
- 已播报的公共事件 ID 保存在浏览器本地，刷新页面不会重复播报旧死讯。
- 每次远程写操作携带房间版本号。服务端先接受的合法操作生效；陈旧请求会被拒绝并触发客户端刷新，不能覆盖已完成的步骤。

## 当前限制

- 浏览器语音依赖 Web Speech API；若系统禁止自动播放，可点击“重播当前台词”。
- 控制权转让必须由当前控制设备生成六位转让码；暂不支持控制设备彻底丢失后的无凭据找回。
- 系统会在公开死亡、延迟死亡、死亡技能和白天放逐结算完成后自动判断胜负并播报；控制设备仍可随时手动结束游戏。
- 五个复杂版型均已通过连续两夜端到端测试。

## 规则校验补充

- 女巫首夜不能自救，解药和毒药各限一次。
- 已使用的药剂请求由服务端明确拒绝，不会静默跳过。
- 毒药只能选择当前存活玩家。
- 屠边统计中，混血儿始终属于平民边；选择狼人榜样只改变胜利归属，不会加入狼队、睁眼或带刀。
- 同一夜狼人先完成屠边、最后一狼随后死亡时，按行动顺序判狼人获胜。
- 混血儿即使跟随狼人也没有自爆入口；非狼人玩家伪造自爆请求会被服务端拒绝。
