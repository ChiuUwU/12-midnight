# 当前状态与发布基线

更新时间：2026-08-10。本文是当前实现、发布与验收状态的唯一简明入口；历史方案和交接快照仅作追溯，不覆盖本文。

## 当前发布基线

- 线上地址：<https://12-midnight.pages.dev/>
- 发布方式：GitHub `main` 合并后由 Cloudflare Pages 自动部署。
- 本次状态核验基线：`main` 的 `79bb5ed`（修复房间页渲染依赖顺序）。
- 自动测试：`npm.cmd test`，2026-08-10 本地结果为 30/30 通过。

## 已实现范围

- 七个固定版型：预女猎白混、假面舞会、盗宝大师、机械狼通灵师、诡术之境、曙光航纪、唯邻是从。
- 有法官与无法官两种房间模式；无法官模式支持玩家各自手机提交私密夜间行动、公共设备播报和公开结果。
- 夜间结算由共享规则模块计算；法官模式须记录当日天亮死亡与放逐结果后才能进入下一夜。上警、退水、警徽记录为可选。
- 夜间和房间轮询不会重绘带有未提交选择或输入的页面，避免清空用户操作。

## 仍需验收或后续处理

- 真实浏览器与手机端验收由产品负责人进行，重点覆盖夜间选择保留、女巫药剂、无法官十秒播报、七个版型的完整流程。
- 无法官模式暂不处理行动超时、控制设备迁移和多设备争抢控制权。
- D1 当前保存整间房间 JSON；房间量显著增长后再评估拆表。
