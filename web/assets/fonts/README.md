# 首页标题字

`last-night-title.woff` 是站酷小薇（ZCOOL XiaoWei）的“最后一夜”四字子集，仅用于首页标题；正文与其他页面字体不变。文件本地托管，不依赖外部字体服务。

来源：https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei

Copyright 2018 The ZCOOL XiaoWei Project Authors (https://github.com/googlefonts/zcool-xiaowei/)

许可证：同目录 `OFL-ZCOOL-XiaoWei.txt`（SIL Open Font License 1.1）。子集文件继续遵守该许可证。

生成命令：`python -m fontTools.subset ZCOOLXiaoWei-Regular.ttf --text="最后一夜" --flavor=woff --output-file=last-night-title.woff`。原始字体保存在本轮集中备份中，未安装系统字体、未安装新依赖。
