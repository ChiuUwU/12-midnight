# 版型开发中：暗黑破坏 2.0

> 文档定位：暗黑破坏 2.0 的独立规则文档，也是网页规则生成源之一；实现及验收进度见 [当前状态](./current-status.md)。

> 规则已确认，当前工作区已接入主要网页流程；尚待完整浏览器验收、无法官模式端到端测试与发布。工作区实现不代表线上已发布。
> 女巫不能自救、同一晚不能同时使用解药和毒药，以及摄梦人不可自摄、摄梦人夜间出局带走当夜梦游者，沿用全局规则。

## 1. 身份组成与胜利条件

12 人局，共 4 神、4 民、4 狼：

| 类别 | 身份 | 数量 |
|---|---|---:|
| 神职 | 天使长、凯恩、女巫、摄梦人 | 各 1 |
| 平民 | 平民 | 4 |
| 狼人 | 普通狼人、狼王、莉莉丝、莉娅 | 各 1 |

- 好人阵营胜利：四名狼人全部出局。
- 狼人阵营胜利：四名神职全部出局，或四名平民全部出局。
- 胜负检查在天使长的复活窗口结束后进行。
- “阵营”与“类别”不可混用：胜负阵营及发牌平衡中的阵营为**狼人 / 好人**两阵营；凯恩鉴定使用**神 / 民 / 狼**三类别。

## 2. 夜间行动顺序

每夜按以下顺序提示；已出局、当夜被禁锢或已用完次数的技能不执行。莉娅不参加狼队互认；当其成为最后一狼时，按狼人步骤单独执行狼刀。整夜是单一连续流程：首夜在莉莉丝后插入莉娅举手确认，莉娅充能/开雾固定在所有其他夜间步骤之后；不得切换到另一套夜间流程或重复播报已完成步骤。

1. **莉莉丝**选择禁锢目标。
2. **首夜莉娅举手确认身份**。这是身份核验步骤，与充能分开，不消耗充能机会。
3. **摄梦人**选择梦游者。
4. **狼人行动**：普通狼人、狼王、莉莉丝共同选择狼刀目标；若其余三狼均已出局，则莉娅继承狼刀。
5. **女巫**选择是否使用解药或毒药。
6. **天使长**选择是否祝福及祝福目标。
7. **凯恩**选择两名玩家鉴定身份关系。
8. **莉娅**若尚未充能成功，则选择充能目标；每夜均询问是否开启迷雾。只有已成功充能、开雾机会尚未使用且当夜能够行动时才能选择开启，开雾步骤不选择号码。

## 3. 角色规则

### 天使长

- 祝福、复活各有一次，全局分别计数、互不消耗；均不能选择自己。
- 祝福普通目标：该目标当天的放逐票权重由 1 变为 3；使用后不能再次祝福。
- 祝福目标若为莉莉丝，莉莉丝死亡。该特殊死亡不受摄梦保护或莉莉丝禁锢保护阻止。
- 复活可用于夜间死亡、白天放逐及后续死亡技能造成的出局。每宣布一名玩家出局，在其离场前单独询问天使长是否复活该玩家；不使用则继续处理后续出局者，实际复活一次后本局不再询问。天使长不能复活自己，且天使长出局后不能发动复活。
- 复活窗口先于该玩家的死亡技能。玩家被复活后，该次死亡技能不发动；未被复活时，再按其死亡原因判断死亡技能。
- 天使长曾被莉莉丝禁锢，复活能力永久消失；禁锢解除后仍可使用尚未消耗的祝福。

### 凯恩

- 每晚选择两名不同玩家鉴定，不能选择自己。
- 两人同为神、同为民或同为狼，反馈“同类”；具体身份可以不同。
- 一神一民，反馈“向下”；一狼一好人，反馈“狼爪”。
- 组合中只要包含莉娅，固定反馈“同类”。

| 组合示例 | 反馈 |
|---|---|
| 女巫 + 天使长 | 同类（同为神） |
| 普通狼人 + 狼王 | 同类（同为狼） |
| 女巫 + 平民 | 向下（一神一民） |
| 普通狼人 + 平民 | 狼爪（一狼一好人） |
| 莉娅 + 任意一人 | 同类（莉娅例外） |

### 莉莉丝

- 每晚先选择一名玩家禁锢；不能禁锢自己，也不能连续两晚禁锢同一人。
- 目标当夜免受夜间伤害；当夜及次日白天不能发动技能；次日不能被放逐。保护也能挡住连续两晚摄梦造成的梦死，但不清除连续摄梦记录。
- 被禁锢者仍可投票；投给被禁锢目标的票不生效，但莉娅仍能在迷雾投票中看到这张票。
- 禁锢其他狼人不阻止其参与狼队刀人；禁锢提供的保护效果仍生效。被禁锢的狼人和狼王次日白天不能自爆，也不能发动其他白天技能。
- 禁锢女巫：女巫当晚不知道刀口，也不能进入用药流程；药瓶保留，不视为消耗。若女巫未被禁锢但狼刀目标被禁锢，女巫仍能看到狼刀目标。
- 对禁锢目标使用的解药或毒药仍消耗药瓶，但不产生效果；目标被保护不改变狼队已提交的狼刀目标。
- 禁锢天使长：复活能力永久消失；禁锢解除后，未使用的祝福仍可用。

### 莉娅

- 与其他狼人互不认识，不能自爆；免疫女巫毒药。毒药作用于莉娅时无效，但毒药仍会消耗。
- 每晚可选择一名玩家充能。目标是平民才算成功；选错身份可在下一晚重试。
- 充能成功后，本局不能再次充能，并获得一次开启迷雾的机会。可在成功当夜或之后选择开启；若当夜未开，充能机会保留。
- 莉娅已选择开启的迷雾，当天即使莉娅出局也照常生效。
- 其余三名狼人全部出局后，莉娅继承狼刀。她仍可在同一夜执行狼刀与充能/开雾步骤；若被莉莉丝禁锢，当晚不能充能或开启迷雾，但禁锢不取消其作为狼人的狼刀资格。

### 女巫

- 解药、毒药各一瓶，全局各可使用一次；每晚最多使用其中一瓶。
- 解药救当晚狼刀刀口；毒药指定一名玩家。
- 女巫不能自救，也不能同一晚同时使用解药和毒药。
- 解药使用后，之后夜晚不再获知刀口；保留解药时，由法官告知刀口，再决定是否使用。
- 被莉莉丝禁锢时，当晚既不知道刀口，也不能使用药物；药瓶不消耗。

### 摄梦人

- 每晚选择一名玩家作为梦游者，不能选择自己；梦游者不知道自己被摄梦。
- 梦游者当夜免疫夜间伤害，包括狼刀和女巫毒药。
- 连续两晚梦同一人，**出局的是该梦游者**，不是摄梦人。
- 摄梦人夜间出局时，当晚梦游者一并出局；摄梦人不能摄梦自己。
- 莉莉丝禁锢摄梦人时，摄梦人当夜仍可选择目标，但摄梦不生效；被禁锢的摄梦人当夜及次日白天无法出局。次日警下公告禁锢号码后，摄梦人可据此知晓自己被禁锢。
- 禁锢不清除此前的连续目标记录；解除禁锢后，连续梦判定延续。

### 狼王与普通狼人

- 普通狼人参与狼队夜间共同刀人。
- 狼王出局时可发动技能带走一人；被毒杀，或因连续两晚被摄梦同一目标而出局时，不能发动技能。
- 狼王作为狼人阵营最后一狼时，仍遵循全局“最后一狼不能发动死亡技能”的限制。

## 4. 迷雾与白天投票

- 警长竞选照常进行；每天警下公布昨夜被禁锢的号码，若无人被禁锢则公布无人被禁锢，并公布迷雾开启或未开启。首日须先结束警上再公布。
- 若迷雾开启，当天放逐投票前还要再次提醒戴盔投票。警长竞选的线上记录可选。
- 无法官模式由公共控制设备触发警下公告及必要的投票前提醒，但控制设备不因此获得完整票型；迷雾开启时仅莉娅能查看具体投票，控制设备只见投票进度与公开结果。
- 迷雾投票时全员戴盔投票；莉娅可确认所有玩家的具体投票，包括弃票。
- 其他玩家只获知最高票玩家的号码及票数，其余票型不公开。若并列最高票，按全局平票 / PK 规则处理，并公布并列最高票号码及票数。
- 被莉莉丝禁锢的玩家仍能投票；投给该禁锢目标的票无效，不计入其放逐票数。莉娅仍能看到这些原始投票。
- 天使长祝福普通存活玩家后，该玩家当天投票权重为 3 票；祝福莉莉丝只触发死亡，不提供三票权重。
- 无法官模式线上逐座位私密收集白天投票并保留弃票；迷雾开启时只有莉娅可在手机上查看完整票型（含弃票），其他玩家只看到最高票号码及票数。迷雾未开启时公开常规票型。
- 有法官模式由法官记录线下票型，并在线下私下告知莉娅完整票型；玩家手机不提供白天投票或技能按钮。

## 5. 结算示例

1. **充能失败后重试**：莉娅首夜充能选中神职，失败；第二夜改选平民，成功。之后不能再充能，但可当夜或之后再开启迷雾。
2. **充能成功后莉娅出局**：莉娅夜间选择开启迷雾后，次日即使被放逐，迷雾投票仍按规则进行。
3. **莉莉丝禁锢女巫**：女巫当晚看不到刀口、不能用药；药瓶保留，解除禁锢后仍可使用。
4. **莉莉丝禁锢摄梦人**：当夜仍可选目标但摄梦不生效，摄梦人当夜及次日白天无法出局；此前连续目标记录保留，恢复行动后再次选择此前目标，按连续梦规则结算，该梦游者出局。
5. **凯恩组合含莉娅**：无论另一个目标属于神、民还是狼，均反馈同类。
6. **莉娅被女巫毒**：莉娅不受毒药影响，但女巫毒药仍消耗。
7. **天使长祝福莉莉丝**：莉莉丝死亡；摄梦或莉莉丝禁锢的保护不能阻止该特殊死亡。
8. **胜负与复活**：若刚发生的死亡看起来满足胜利条件，先完成天使长可用的复活窗口，再检查胜利条件。
9. **禁锢与用药**：女巫未被禁锢，狼刀目标被禁锢时，她仍看见刀口；若选择解药，药瓶消耗，但目标本就免疫狼刀。对被禁锢目标使用毒药同样消耗毒药，但目标不受伤害。
10. **天使长与狼王**：狼王出局后先给天使长复活窗口；若狼王被复活，不发动带人技能；若天使长不复活，再按死因判断狼王能否发动技能。
