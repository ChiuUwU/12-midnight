## 2. 相邻座位与傀儡

- 座位按环形相邻：1 号相邻 12 号、2 号；12 号相邻 11 号、1 号。
- 首夜，狼王和两名狼人共同从**所有狼人座位的左右相邻座位**中，选择一名非狼人玩家作为傀儡。
- 若候选座位重叠，只保留一个候选座位；例如狼人位于 1、5、6 号时，候选为 12、2、4、7 号。
- 傀儡首夜必须选择一次，整局固定，不能更换或重复选择；傀儡死亡后正常出局，不再产生新的傀儡。
- 傀儡不会在夜间睁眼，不与狼队互认，不拥有狼队击杀能力，也不会得知自己是傀儡。
- 平民可以成为傀儡；除被预言家查验为狼人阵营外，没有额外效果。

## 3. 首夜与后续夜间流程

首夜：

1. 守卫睁眼，正常选择守护对象。
2. 狼王和狼人一起睁眼：先共同确定傀儡，再正常共同确定狼刀目标。
3. 女巫睁眼，正常选择是否使用解药、毒药。
4. 预言家睁眼，正常选择查验对象。

后续夜晚不再选择傀儡；守卫、狼队、女巫、预言家继续按正常流程行动。狼队每夜均可正常刀人。

## 4. 傀儡效果

| 傀儡身份 | 规则 |
|------|------|
| 任意身份 | 被预言家查验时，结果显示为狼人阵营。 |
| 平民 | 仅受“查验为狼”影响。 |
| 预言家 | 其查验结果反转：查狼人、狼王和傀儡为金水；查其他身份为查杀。 |
| 女巫 | 仍可正常选择用药；解药、毒药照常消耗，但均不产生效果。 |
| 守卫 | 仍可正常选择守护；操作照常记录，但不产生任何守护效果，不能挡刀。 |
| 猎人 | 出局后界面按正常规则显示开枪资格；若非中毒死亡，仍可选定目标并确认开枪。系统记录一次空枪，但不产生击杀，也不弹出“傀儡导致失败”的提示。中毒当夜仍按普通猎人规则显示不能开枪。 |

所有傀儡效果均应在结算层静默生效：系统不得通过错误提示、额外文案、公开日志或权限差异直接告知玩家其傀儡身份。技能未产生预期结果本身可能让玩家推测，但这不是系统的主动泄露。

## 5. 发牌平衡规则（已确认）

> 本节以下旧“未定”文字保留为决策记录；以本框规则为准。

- 保留现有“伪随机 + 阵营实力平衡 + 最近十局身份/阵营轮换”的 2,000 个候选发牌与加权抽样机制。
- 不禁止三狼连坐、两狼连坐，也不禁止同一神职同时与两名狼相邻；这些均是合法排列。
- 对每个候选，取三名狼左右邻座的去重并集，排除狼人座位，再统计其中不同神职人数 `U`；同一神职即使邻接两名狼也只计 1 人。
- 仅在 `U < 2` 时加入软惩罚：`8 × (2 - U)²`。惩罚进入原有温度为 3 的加权抽样，不构成重发、禁止或硬约束。
- 目标是长期样本的 `E[U]` 落在 2–3，初始验收目标约 2.3–2.5。单局不要求落在均值附近；三狼连坐且两侧各一神时 `U=2` 是合法且不受惩罚的排列。

本版型的目标是让狼人相邻位置存在神职牌，以使首夜傀儡选择具有博弈空间。以下细节尚未确认：

- 是否要求每一名狼人的左右相邻座位都至少包含一张神职牌；
- 所需相邻神职的最少数量；
- 在均衡发牌候选中满足该条件的目标概率、权重和不满足时的回退策略；
- 候选傀儡不足时是否允许重发牌或采用其他补偿规则。

在这些参数明确前，本版型只能作为规则设计文档存在，不能加入 `BOARDS`、均衡发牌或线上房间创建入口。

## 6. 实现验收要点（后续）

1. 环形相邻关系正确处理 1 号与 12 号。
2. 首夜候选为全部狼人左右邻座的去重并集，且排除狼人座位。
3. 傀儡只可在首夜确定一次，后续夜晚不可更改。
4. 傀儡不出现在狼队见面名单、狼刀权限或公开信息中。
5. 五类傀儡效果分别覆盖查验、反转查验、耗药失效、守护失效和猎人空枪。
6. 非傀儡玩家的同类技能行为与现有版型保持一致。
7. 发牌约束确定后，必须对 Node、本地静态模式和 Cloudflare Pages Function 同时增加回归测试。
